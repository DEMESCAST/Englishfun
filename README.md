# English Fun 🎮

Aprenda Inglês brincando! Jogo educativo para crianças.

## Funcionalidades

- 🐾 11 categorias com 25 palavras cada
- 🎯 Quiz interativo com pronúncia
- 🔊 Áudio com pronúncia em inglês
- 🏆 Sistema de conquistas
- 📊 Progresso salvo
- 📱 Funciona em celular e computador

## Categorias

- Animais
- Comidas  
- Cores
- Números
- Corpo
- Objetos
- Família
- Roupas
- Clima
- Ações
- Frases

## Como Jogar

1. Escolha a dificuldade (Fácil, Médio, Difícil)
2. Selecione uma categoria
3. Aprenda as palavras
4. Responda o quiz
5. Tente acertar todas!

## Tecnologias

- HTML5
- CSS3
- JavaScript vanilla
- Web Speech API (áudio)
